## 常用求导公式总结

## 一、基本初等函数导数

| 函数 | 导数 |
|---|---|
| $C$（常数） | $0$ |
| $x^n$ | $n x^{n-1}$ |
| $\sqrt{x}$ | $\dfrac{1}{2\sqrt{x}}$ |
| $\dfrac{1}{x}$ | $-\dfrac{1}{x^2}$ |
| $e^x$ | $e^x$ |
| $a^x$ | $a^x \ln a$ |
| $\ln x$ | $\dfrac{1}{x}$ |
| $\log_a x$ | $\dfrac{1}{x \ln a}$ |
| $\sin x$ | $\cos x$ |
| $\cos x$ | $-\sin x$ |
| $\tan x$ | $\sec^2 x = \dfrac{1}{\cos^2 x}$ |
| $\cot x$ | $-\csc^2 x = -\dfrac{1}{\sin^2 x}$ |
| $\sec x$ | $\sec x \tan x$ |
| $\csc x$ | $-\csc x \cot x$ |
| $\arcsin x$ | $\dfrac{1}{\sqrt{1-x^2}}$ |
| $\arccos x$ | $-\dfrac{1}{\sqrt{1-x^2}}$ |
| $\arctan x$ | $\dfrac{1}{1+x^2}$ |
| $\operatorname{arccot} x$ | $-\dfrac{1}{1+x^2}$ |
| $\sinh x$ | $\cosh x$ |
| $\cosh x$ | $\sinh x$ |
| $\tanh x$ | $\operatorname{sech}^2 x$ |

## 二、四则运算求导法则

设 $u=u(x)$，$v=v(x)$ 均可导：

| 法则 | 公式 |
|---|---|
| 和差 | $(u \pm v)' = u' \pm v'$ |
| 常数倍 | $(Cu)' = C u'$ |
| 乘积 | $(uv)' = u'v + uv'$ |
| 商 | $\left(\dfrac{u}{v}\right)' = \dfrac{u'v - uv'}{v^2}$ |
| 倒数 | $\left(\dfrac{1}{v}\right)' = -\dfrac{v'}{v^2}$ |

---

## 三、复合函数与反函数

| 类型 | 公式 |
|---|---|
| 链式法则 | $\dfrac{dy}{dx} = \dfrac{dy}{du} \cdot \dfrac{du}{dx}$ |
| 反函数 | $\dfrac{dy}{dx} = \dfrac{1}{\dfrac{dx}{dy}}$ |
| 对数求导 | 适用于 $y=u^v$ 或乘除幂形式，先取对数再求导 |

---

## 四、高阶导数常用公式

| 函数 | $n$ 阶导数 |
|---|---|
| $e^x$ | $e^x$ |
| $a^x$ | $a^x (\ln a)^n$ |
| $\sin x$ | $\sin\left(x + \dfrac{n\pi}{2}\right)$ |
| $\cos x$ | $\cos\left(x + \dfrac{n\pi}{2}\right)$ |
| $x^n$ | $n!$（当 $n$ 为正整数时） |
| $\ln x$ | $(-1)^{n-1}\dfrac{(n-1)!}{x^n}$ |
| $\dfrac{1}{x}$ | $(-1)^n \dfrac{n!}{x^{n+1}}$ |

---

## 五、常用记忆技巧

1. **幂函数**：指数减一，系数乘原指数
2. **指数函数**：$e^x$ 不变；$a^x$ 多乘 $\ln a$
3. **对数函数**：$\ln x$ 导数是 $\dfrac{1}{x}$；底数 $a$ 多除 $\ln a$
4. **三角函数**：正变余，余变负正；正切变正割平方
5. **反三角函数**：分母都是 $1+x^2$ 或 $\sqrt{1-x^2}$
