# RuoYi-Vue 企业级运维管理平台

> 基于 **RuoYi-Vue v3.9.2**（Spring Boot 4.x + Vue 2.x）二次开发的企业级运维管理平台，集成资产全生命周期管理、巡检作业闭环、权限管控、定时任务调度、代码自动生成及全自动化 CI/CD 流水线。

---

## 🎯 项目背景

针对企业 IT 运维场景中“资产台账分散、巡检流程依赖人工、权限管控粗放、发布流程繁琐”等痛点，在 RuoYi-Vue 成熟权限框架基础上，扩展构建**运维业务域**，实现从“通用后台”到“运维专用平台”的演进。

## 🧩 核心功能模块

### 1. 服务器资产管理（新增核心业务）

- **资产全生命周期**：录入、变更、维修、报废、转移、导入导出
- **多维检索**：IP/机房/业务分组/运维责任人/资产状态组合查询
- **关联联动**：一键跳转关联巡检记录、监控告警历史、变更工单
- **批量操作**：Excel 模板导入、批量状态变更、二维码标签打印

### 2. 巡检记录管理（新增核心业务）

- **任务下发**：周期性/临时巡检任务，支持 Cron 表达式可视化配置（Crontab 组件）
- **移动端友好**：扫码录入、GPS 定位、拍照上传、离线缓存同步
- **异常闭环**：异常项自动生成工单 → 指派处理 → 整改复核 → 关闭，全流程留痕
- **统计看板**：ECharts 渲染巡检完成率、异常分布热力图、人员工作量排行

### 3. 系统基础框架（RuoYi 核心能力）

| 模块 | 关键特性 |
|------|----------|
| 用户/角色/菜单/部门 | 树形结构、数据范围权限、动态路由 |
| 字典/参数/通知 | 缓存化高频读取、实时生效 |
| 日志审计 | 操作日志/登录日志/异常日志，异步写入、分页导出 |
| 定时任务 | Quartz 集群模式、分布式锁防重、执行日志追踪、钉钉/邮件告警 |
| 代码生成 | 30+ 模板（Entity/Mapper/Service/Controller/Vue/SQL），一键生成 CRUD |
| 在线构建器 | 拖拽表单生成 HTML、支持自定义组件 |

### 4. 安全体系

- **认证**：JWT + Redis 无状态登录，Token 滑动续期（默认 30 分钟）
- **授权**：RBAC 细粒度到**按钮级** + **数据范围级**（部门/自定义）
- **防护**：XSS 过滤、SQL 注入防护、重放攻击防御、验证码/限流

🛠️ 技术难点与解决方案
难点	解决方案	核心收获
动态表单配置化（巡检项）	JSON Schema + Vue 递归渲染 + 7 种字段类型 + Crontab 可视化	深入掌握 Vue h()、动态校验、组件解耦
分布式定时任务防重	Redis SETNX + Lua 脚本分布式锁 + @DisallowConcurrentExecution 双重保障	理解分布式锁原理、时钟漂移影响、幂等性设计
CI/CD 环境一致性	Dockerfile 多阶段构建 + Maven/Node 缓存卷 + 阿里云镜像源统一	消除“在我机器上能跑”，掌握分层缓存优化
Webhook 并发风暴	Pipeline concurrency + 幂等性判断 + Quiet Period	实战 CI 背压设计、幂等模式、队列治理
